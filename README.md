# proj02
Template repository for Project 2, Stat 159/259 Fall 2025
This project analyzes the word frequencies of speeches by American presidents and how their usage changes over time. We had to clean data so we could evaluate traditional and transformer-based topic models to identify and interpret meaningful themes in political speech.
